# BOOK 스캔 페이지별 건축 용어 정리

> 이 문서는 69개 스캔의 **페이지별 해설본**이다. 설명 없이 용어만 정리한 파일은 [BOOK 건축용어 단어목록](./BOOK_건축용어_단어목록.md), 상세 분류본은 [BOOK 건축언어 전체 추출](./BOOK_건축언어_전체추출.md), 엑셀용 데이터는 [BOOK 건축언어 전체 목록 CSV](./BOOK_건축언어_전체목록.csv)를 참고한다.

## 1. 이 책을 읽는 핵심

이 자료는 건축 형태를 완성된 물체가 아니라 **동사로 변화하는 과정**으로 보는 설계 문법이다. 일상 언어의 동사(늘리다, 비틀다, 파내다 등)를 매스와 공간에 적용하고, 그 결과를 다시 조합하거나 반복하여 더 복잡한 형태를 만든다.

책의 기본 순서는 다음과 같다.

1. **Base Volume(기본 볼륨)**을 정한다.
2. 하나의 **Operation(형태 조작)**을 적용한다.
3. 크기, 비례, 방향을 바꾸어 **Variation(변형안)**을 만든다.
4. 조작을 연속 적용하는 **Combination(조합)** 또는 결과를 반복 배치하는 **Aggregation(집합)**으로 확장한다.
5. 실제 건축물의 프로그램, 동선, 빛, 매스 구성에 대응시킨다.

> 스캔 이미지 한 장에는 실제 책의 두 페이지가 들어 있다. 스캔 1과 2는 같은 책 10–11쪽의 중복 촬영본이며, 책 12–13쪽은 현재 폴더에 없다. 스캔 3부터는 `책 쪽수 = 스캔 번호 × 2 + 8`로 대응한다.

## 2. 전체 분류

| 상위 분류 | 뜻 | 단일/복수 볼륨 | 포함 동사 |
|---|---|---|---|
| **Add** | 기존 매스에 체적을 더하거나 체적 관계를 확장 | Single | Expand, Extrude, Inflate |
| **Add** | 여러 매스를 결합하여 새 전체를 만듦 | Multiple | Branch, Merge, Nest, Offset |
| **Displace** | 체적량보다 위치·방향·관계를 바꿈 | Single | Bend, Skew, Split, Twist |
| **Displace** | 여러 매스 사이의 접촉·교차·배치를 바꿈 | Multiple | Interlock, Intersect, Lift, Lodge, Overlap, Rotate, Shift |
| **Subtract** | 기존 매스에서 체적을 덜어냄 | Single | Carve, Compress, Fracture, Grade, Notch, Pinch, Shear, Taper |
| **Subtract** | 다른 볼륨을 절삭 도구처럼 사용 | Multiple | Embed, Extract, Inscribe, Puncture |

색상도 분류를 돕는다. 책의 도식에서 Add는 녹색 계열, Displace는 주황·적색 계열, Subtract는 청색·청록 계열로 표현된다.

## 3. 건축 형태 조작 용어 사전

### 3.1 Add — 더하기

| 영문 | 권장 한국어 | 도식의 의미 | 건축적으로 읽는 법 |
|---|---|---|---|
| **Expand** | 확장하다 | 한쪽 경계나 면을 밀어 기존 볼륨의 범위를 늘림 | 방 또는 매스를 한 방향으로 연장해 면적과 외곽을 확장 |
| **Extrude** | 돌출하다, 압출하다 | 면의 일부를 직선 방향으로 뽑아 새 돌출부를 만듦 | 발코니, 돌출 창, 캔틸레버, 부속 공간을 생성 |
| **Inflate** | 팽창시키다 | 중심부 또는 대응하는 두 경계를 바깥으로 벌려 부풀림 | 특정 구간의 폭·단면을 키워 중심 공간이나 강조 매스를 형성 |
| **Branch** | 분기하다 | 하나의 줄기에서 둘 이상의 팔이 갈라져 나감 | 복도·프로그램·동선이 여러 방향으로 분기되는 조직 |
| **Merge** | 병합하다 | 떨어진 볼륨을 겹쳐 경계를 지우고 하나의 연속 매스로 만듦 | 여러 프로그램을 하나의 통합된 건물 덩어리로 결합 |
| **Nest** | 포개 넣다, 내포하다 | 작은 볼륨을 큰 볼륨 안에 넣어 안과 밖의 위계를 만듦 | 방 속의 방, 코어 속 프로그램, 이중 외피 같은 중첩 공간 |
| **Offset** | 평행 이격하다 | 원래 경계와 일정 거리를 둔 평행 경계를 안팎에 추가 | 이중 외피, 회랑, 완충층, 벽 두께, 띠 모양 공간을 생성 |

### 3.2 Displace — 변위·재배치

| 영문 | 권장 한국어 | 도식의 의미 | 건축적으로 읽는 법 |
|---|---|---|---|
| **Bend** | 굽히다 | 볼륨의 일부를 꺾되 전체 연결은 유지 | 대지 경계나 동선을 따라 매스를 꺾고 방향을 전환 |
| **Skew** | 비스듬히 밀다, 사행 변형 | 한 면을 평행 이동하여 직각 체계를 사선형으로 바꿈 | 사선 벽, 비정형 평면, 시선 방향을 강조 |
| **Split** | 가르다, 분할 변위하다 | 단일 볼륨을 갈라 일부를 다른 방향으로 벌림 | 하나의 프로그램을 두 갈래로 나누면서 중심 틈이나 분기 공간을 만듦 |
| **Twist** | 비틀다 | 양 끝 또는 단면을 서로 다른 방향으로 회전 | 층별 방향 변화, 비틀린 입면, 시선과 동선의 연속 회전 |
| **Interlock** | 맞물리다 | 홈이나 돌출부가 서로 끼워지도록 결합 | 프로그램이 퍼즐처럼 물리며 경계와 공유 공간을 만듦 |
| **Intersect** | 관통 교차하다 | 두 볼륨이 서로를 가로질러 교차 | 교차부를 결절점, 공용 공간, 수직·수평 동선의 중심으로 사용 |
| **Lift** | 들어 올리다 | 한 볼륨을 다른 볼륨 위로 올려 접촉 관계를 바꿈 | 필로티, 띄운 매스, 하부 공공 공간 또는 단차 형성 |
| **Lodge** | 끼워 고정하다, 걸치다 | 두 볼륨 사이에 제3의 볼륨을 끼워 연결 | 브리지, 연결 코어, 사이 공간을 잇는 매개 매스 |
| **Overlap** | 겹치다 | 두 볼륨 일부를 포개되 각각의 형상도 읽히게 유지 | 프로그램 공유 영역, 중첩 구역, 복합 경계를 형성 |
| **Rotate** | 회전하다 | 한 볼륨을 기준점이나 축 주위로 돌림 | 대지·조망·일조에 대응하여 매스 방향을 변화 |
| **Shift** | 어긋나게 이동하다 | 인접한 볼륨을 평행 이동시켜 단차를 만듦 | 세트백, 테라스, 어긋난 층, 지그재그 입면을 형성 |

### 3.3 Subtract — 빼기

| 영문 | 권장 한국어 | 도식의 의미 | 건축적으로 읽는 법 |
|---|---|---|---|
| **Carve** | 파내다 | 외부에서 안쪽으로 큰 덩어리를 도려내 깊은 빈 공간을 만듦 | 중정, 아트리움, 포치, 진입부, 큰 개구부 형성 |
| **Compress** | 압축하다 | 대응하는 경계를 안쪽으로 밀어 전체 폭이나 두께를 줄임 | 좁아지는 통로, 압축된 매스, 공간의 긴장과 대비 형성 |
| **Fracture** | 균열 내다, 쪼개다 | 불규칙하거나 사선인 틈을 절삭해 덩어리를 갈라 보이게 함 | 균열형 보이드, 빛의 틈, 매스 분절을 강조 |
| **Grade** | 단차화하다 | 단계적으로 체적을 깎아 계단형 윤곽을 만듦 | 계단식 지붕, 테라스, 경사지 적응형 매스 |
| **Notch** | 홈 파다 | 모서리나 변에서 국부적으로 V자·사각 홈을 제거 | 출입구, 작은 테라스, 채광 홈, 코너 후퇴 |
| **Pinch** | 잘록하게 조이다 | 중앙부 양쪽을 깎아 허리가 좁아지게 함 | 중앙 연결부, 좁은 전이 공간, 모래시계형 평면·단면 |
| **Shear** | 사선 절단하다 | 사선 평면으로 한 부분을 잘라 냄 | 비스듬한 지붕·입면, 일조 사선, 대지 경계 대응 |
| **Taper** | 점차 가늘게 하다 | 길이를 따라 양측을 점진적으로 깎아 한쪽 단면을 줄임 | 끝으로 좁아지는 매스, 원근감·방향성·채광 조절 |
| **Embed** | 파묻다, 끼워 넣다 | 제2 볼륨을 제1 볼륨에 밀어 넣어 자리와 절삭 흔적을 만듦 | 삽입된 방·코어·설비, 매스 속에 박힌 프로그램 |
| **Extract** | 빼내다, 추출하다 | 제2 볼륨이 겹친 부분을 밖으로 빼내며 그 자리를 비움 | 제거된 방, 중정, 포켓 보이드, 음각 공간 형성 |
| **Inscribe** | 새겨 넣다 | 가느다란 제2 볼륨으로 표면이나 가장자리에 연속 홈을 냄 | 선형 채광 틈, 입면 홈, 동선 흔적, 긴 절개부 |
| **Puncture** | 관통시키다 | 하나 이상의 작은 볼륨으로 매스를 뚫어 관통공을 만듦 | 창, 천창, 통풍구, 관통 통로, 다공성 외피 형성 |

### 3.4 Aggregation — 집합 방식

| 영문 | 권장 한국어 | 의미 |
|---|---|---|
| **Reflect** | 반사 복제 | 기준축을 중심으로 거울상 복사하여 대칭 또는 교대 패턴을 만듦 |
| **Pack** | 밀집 배치 | 단위 사이의 빈틈을 최소화하며 촘촘하게 채움 |
| **Stack** | 적층 | 단위를 수직 또는 층상으로 쌓음 |
| **Array** | 배열 | 일정한 간격·행·열·규칙으로 반복 배치 |
| **Join** | 이어 붙이기 | 단위의 끝이나 접점을 연결해 사슬·띠·네트워크를 만듦 |

### 3.5 자주 나오는 보조 용어

| 영문 | 한국어 풀이 |
|---|---|
| **Base Volume** | 형태 조작을 시작하는 기본 매스 |
| **Single Volume** | 하나의 연속된 볼륨을 대상으로 함 |
| **Multi Volume / Multiple** | 둘 이상의 볼륨 관계를 대상으로 함 |
| **Orientation** | 볼륨 또는 조작의 방향·배치 각도 |
| **Variation** | 크기, 비례, 방향, 위치를 달리한 변형안 |
| **Operation** | 매스에 적용하는 형태 조작 |
| **Combination** | 둘 이상의 조작을 순서대로 적용하는 것 |
| **Aggregation** | 조작된 단위를 반복·집합하는 방식 |
| **Massing** | 건물의 전체 덩어리와 체적 구성 |
| **Program** | 건물 안에 들어가는 기능과 활동의 구성 |
| **Plinth** | 건물을 받치는 기단 또는 저층부 받침 매스 |
| **Core** | 계단, 엘리베이터, 설비, 서비스 기능이 집중된 중심부 |
| **Light Well** | 내부 깊숙이 빛과 공기를 들이는 수직 채광정 |
| **Circulation** | 사람의 이동 체계와 동선 |

## 4. 스캔 페이지별 정리

### 스캔 01 — 책 10–11쪽: Generative Process / Combinations and Aggregations

- 책의 출발점은 일상적인 동작 언어를 공간 사고에 적용하는 것이다. 동사를 쓰면 설계를 고정된 결과가 아니라 계속 변하는 능동적 과정으로 볼 수 있다.
- 제시된 목록은 규칙이나 정답이 아니라 더 큰 가능성 중 일부다. 볼륨의 비례, 적용 방향, 프로그램 요구에 따라 같은 동사도 다른 결과를 낸다.
- Combination은 서로 다른 조작을 연결하는 **chain(연쇄)** 방식이고, Aggregation은 Reflect, Pack, Stack, Array, Join의 다섯 방식으로 정리된다.
- 원본: [스캔 01](./스캔_smallpdf_1.jpg)

### 스캔 02 — 책 10–11쪽 중복본

- 스캔 01과 같은 내용을 다시 촬영한 파일이다. OCR 상태는 조금 다르지만 내용상 새 페이지는 아니다.
- 책 12–13쪽에 해당하는 스캔은 현재 폴더에 없다.
- 원본: [스캔 02](./스캔_smallpdf_2.jpg)

### 스캔 03 — 책 14–15쪽: Base Volumes

- 모든 실험의 출발이 되는 기본 볼륨을 크기별로 제시한다: 1/1, 3/8, 1/2, 1/4, 1/8, 1/16.
- 같은 조작이라도 기본 볼륨의 비율과 크기가 달라지면 결합부, 공간 위계, 전체 실루엣이 달라진다는 점을 위한 공통 척도다.
- 원본: [스캔 03](./스캔_smallpdf_3.jpg)

### 스캔 04 — 책 16–17쪽: Operations 전체 지도

- 형태 조작을 Add, Displace, Subtract로 나눈 전체 계통도다.
- Add는 Expand–Offset, Displace는 Bend–Shift, Subtract는 Carve–Puncture까지 이어진다.
- 각 분류 안에서 다시 Single과 Multiple로 갈라져, 하나의 매스를 바꾸는지 여러 매스의 관계를 바꾸는지를 구분한다.
- 원본: [스캔 04](./스캔_smallpdf_4.jpg)

### 스캔 05 — 책 18–19쪽: Add 분류 지도

- Add만 따로 확대한 목차다.
- Single Volume은 Expand, Extrude, Inflate이고, Multi Volume은 Branch, Merge, Nest, Offset이다.
- 원본: [스캔 05](./스캔_smallpdf_5.jpg)

### 스캔 06 — 책 20–21쪽: Expand

- **Add / Single Volume.** 한쪽 경계를 바깥으로 이동하여 기본 볼륨을 연장한다.
- 전체가 늘어나지만 기존 매스와의 연속성은 유지된다. 방향과 길이에 따라 사선형·단계형 확장이 가능하다.
- 설계에서는 방 증축, 매스 연장, 외곽선 확장으로 읽을 수 있다.
- 원본: [스캔 06](./스캔_smallpdf_6.jpg)

### 스캔 07 — 책 22–23쪽: Extrude

- **Add / Single Volume.** 면의 일부를 선택해 직선 방향으로 뽑아낸다.
- Expand가 비교적 큰 경계를 늘리는 조작이라면 Extrude는 선택된 국부 면이 돌출된다는 차이가 있다.
- 발코니, 돌출창, 캔틸레버, 부속 실을 만드는 데 대응한다.
- 원본: [스캔 07](./스캔_smallpdf_7.jpg)

### 스캔 08 — 책 24–25쪽: Inflate

- **Add / Single Volume.** 대응하는 두 면을 벌려 중앙 또는 특정 구간을 부풀린다.
- 단순히 길이를 늘리기보다 단면의 폭이 커져 ‘팽창한 중심부’가 생긴다.
- 큰 공용 공간, 강조된 홀, 넓어지는 중간 구간을 설계할 때 유용한 개념이다.
- 원본: [스캔 08](./스캔_smallpdf_8.jpg)

### 스캔 09 — 책 26–27쪽: Branch

- **Add / Multi Volume.** 한 줄기에서 두 개 이상의 볼륨이 갈라져 나오는 Y자형 분기다.
- 분기 각도, 팔의 폭, 방향을 바꾸면 다양한 프로그램·동선 조직이 된다.
- 원본: [스캔 09](./스캔_smallpdf_9.jpg)

### 스캔 10 — 책 28–29쪽: Merge

- **Add / Multi Volume.** 별도의 볼륨을 겹쳐 하나의 연속된 외곽으로 병합한다.
- 겹친 뒤에도 두 단위가 읽히는 Overlap과 달리, Merge는 통합된 한 덩어리로 보는 것이 핵심이다.
- 원본: [스캔 10](./스캔_smallpdf_10.jpg)

### 스캔 11 — 책 30–31쪽: Nest

- **Add / Multi Volume.** 작은 볼륨을 큰 볼륨 안에 넣어 내포 관계를 만든다.
- 크기 차이와 삽입 위치에 따라 중심성, 편심성, 공간의 위계가 달라진다.
- 방 속의 방, 중심 코어, 이중 외피로 해석할 수 있다.
- 원본: [스캔 11](./스캔_smallpdf_11.jpg)

### 스캔 12 — 책 32–33쪽: Offset

- **Add / Multi Volume.** 기존 윤곽과 일정 간격을 둔 평행 윤곽을 추가한다.
- 동심형, 편심형, 부분 오프셋에 따라 띠 공간이나 이중 경계가 만들어진다.
- 회랑, 완충층, 외피 간 공간, 벽 두께를 조직하는 조작이다.
- 원본: [스캔 12](./스캔_smallpdf_12.jpg)

### 스캔 13 — 책 34–35쪽: Displace 분류 지도

- Single Volume은 Bend, Skew, Split, Twist이다.
- Multi Volume은 Interlock, Intersect, Lift, Lodge, Overlap, Rotate, Shift이다.
- 재료를 더하거나 빼는 것보다 매스의 위치·방향·접촉 관계를 바꾸는 분류다.
- 원본: [스캔 13](./스캔_smallpdf_13.jpg)

### 스캔 14 — 책 36–37쪽: Bend

- **Displace / Single Volume.** 한 부분을 꺾어 방향을 바꾸되 볼륨의 연결은 유지한다.
- 꺾이는 위치와 각도가 중요한 변수이며, 대지 경계나 동선 방향에 대응할 수 있다.
- 원본: [스캔 14](./스캔_smallpdf_14.jpg)

### 스캔 15 — 책 38–39쪽: Skew

- **Displace / Single Volume.** 한 면을 옆으로 밀어 직사각형을 평행사변형 또는 사선형으로 바꾼다.
- 전체 축은 유지하면서 벽과 면의 방향을 비스듬히 만들어 시선과 움직임을 유도한다.
- 원본: [스캔 15](./스캔_smallpdf_15.jpg)

### 스캔 16 — 책 40–41쪽: Split

- **Displace / Single Volume.** 하나의 볼륨을 갈라 일부를 벌리거나 다른 방향으로 민다.
- 분할선이 새로운 틈, 진입부, 분기 동선이 되며 Y자형 공간도 만들 수 있다.
- 원본: [스캔 16](./스캔_smallpdf_16.jpg)

### 스캔 17 — 책 42–43쪽: Twist

- **Displace / Single Volume.** 한 단면을 다른 단면에 대해 회전시켜 비튼다.
- 길이를 따라 면의 방향이 연속적으로 변하므로 동적인 입면과 회전 동선에 적합하다.
- 원본: [스캔 17](./스캔_smallpdf_17.jpg)

### 스캔 18 — 책 44–45쪽: Interlock

- **Displace / Multi Volume.** 서로의 빈 자리와 돌출부가 맞물리도록 두 볼륨을 결합한다.
- 단순 중첩보다 결합력이 강하게 읽히며, 공유 공간이나 프로그램 경계가 복합적으로 생긴다.
- 원본: [스캔 18](./스캔_smallpdf_18.jpg)

### 스캔 19 — 책 46–47쪽: Intersect

- **Displace / Multi Volume.** 두 볼륨이 서로 관통하며 교차한다.
- 교차부는 두 체계가 만나는 결절점이고, 공용 공간이나 코어가 되기 쉽다.
- 원본: [스캔 19](./스캔_smallpdf_19.jpg)

### 스캔 20 — 책 48–49쪽: Lift

- **Displace / Multi Volume.** 한 볼륨을 다른 볼륨 위로 들어 올려 높이 차를 만든다.
- 하부가 비워져 필로티·진입 공간이 되거나 상하 프로그램의 위계가 생긴다.
- 원본: [스캔 20](./스캔_smallpdf_20.jpg)

### 스캔 21 — 책 50–51쪽: Lodge

- **Displace / Multi Volume.** 두 볼륨 사이에 작은 연결 볼륨을 끼워 H자형 관계를 만든다.
- 연결 브리지, 공용 코어, 사이 공간을 고정하는 매개체로 해석할 수 있다.
- 원본: [스캔 21](./스캔_smallpdf_21.jpg)

### 스캔 22 — 책 52–53쪽: Overlap

- **Displace / Multi Volume.** 두 볼륨 일부를 겹치되 각 볼륨의 독립된 윤곽을 남긴다.
- 겹친 영역은 프로그램 공유부 또는 전이 구역이 된다.
- 원본: [스캔 22](./스캔_smallpdf_22.jpg)

### 스캔 23 — 책 54–55쪽: Rotate

- **Displace / Multi Volume.** 인접한 볼륨 중 하나를 기준점 주위로 회전한다.
- 회전 각도에 따라 사이 공간이 열리거나 닫히고, 대지·조망·일조에 대한 방향성이 달라진다.
- 원본: [스캔 23](./스캔_smallpdf_23.jpg)

### 스캔 24 — 책 56–57쪽: Shift

- **Displace / Multi Volume.** 인접한 볼륨을 평행 이동하여 서로 어긋나게 한다.
- 세트백, 테라스, 층별 어긋남, 지그재그 매스를 만드는 기본 조작이다.
- 원본: [스캔 24](./스캔_smallpdf_24.jpg)

### 스캔 25 — 책 58–59쪽: Subtract 분류 지도

- Single Volume은 Carve, Compress, Fracture, Grade, Notch, Pinch, Shear, Taper이다.
- Multi Volume은 Embed, Extract, Inscribe, Puncture이다.
- 두 번째 볼륨은 종종 실제 프로그램이 아니라 첫 번째 볼륨을 깎는 절삭 도구로 사용된다.
- 원본: [스캔 25](./스캔_smallpdf_25.jpg)

### 스캔 26 — 책 60–61쪽: Carve

- **Subtract / Single Volume.** 외곽에서 내부로 큰 부분을 파내 깊은 오목 공간을 만든다.
- 절삭 크기와 깊이에 따라 포치, 중정, 아트리움, 큰 출입구가 된다.
- 원본: [스캔 26](./스캔_smallpdf_26.jpg)

### 스캔 27 — 책 62–63쪽: Compress

- **Subtract / Single Volume.** 양쪽 경계를 안으로 밀어 폭이나 두께를 줄인다.
- Inflate와 반대되는 조작이며, 좁아지는 구간과 공간적 압축감을 만든다.
- 원본: [스캔 27](./스캔_smallpdf_27.jpg)

### 스캔 28 — 책 64–65쪽: Fracture

- **Subtract / Single Volume.** 불규칙하거나 사선인 조각을 제거해 균열처럼 갈라진 틈을 만든다.
- 빛이 들어오는 날카로운 보이드, 동선 틈, 분절된 매스를 표현한다.
- 원본: [스캔 28](./스캔_smallpdf_28.jpg)

### 스캔 29 — 책 66–67쪽: Grade

- **Subtract / Single Volume.** 체적을 단계적으로 깎아 계단형 윤곽을 만든다.
- 층별 테라스, 경사지 대응, 일조권 사선에 따른 후퇴 매스로 읽을 수 있다.
- 원본: [스캔 29](./스캔_smallpdf_29.jpg)

### 스캔 30 — 책 68–69쪽: Notch

- **Subtract / Single Volume.** 모서리 또는 변에 국부적인 홈을 낸다.
- Carve보다 작고 국소적이며, 출입구·코너 후퇴·채광 홈을 만드는 데 적합하다.
- 원본: [스캔 30](./스캔_smallpdf_30.jpg)

### 스캔 31 — 책 70–71쪽: Pinch

- **Subtract / Single Volume.** 중앙 양측을 안으로 깎아 잘록한 허리를 만든다.
- 양 끝의 큰 공간을 좁은 연결부로 잇거나 중앙의 긴장감을 강조한다.
- 원본: [스캔 31](./스캔_smallpdf_31.jpg)

### 스캔 32 — 책 72–73쪽: Shear

- **Subtract / Single Volume.** 사선 평면으로 한 부분을 절단한다.
- 여기서 Shear는 구조역학의 전단력보다는 ‘사선으로 베어 내기’에 가깝다.
- 원본: [스캔 32](./스캔_smallpdf_32.jpg)

### 스캔 33 — 책 74–75쪽: Taper

- **Subtract / Single Volume.** 길이를 따라 측면을 점진적으로 깎아 한쪽 단면을 좁힌다.
- 한 방향으로 수렴하는 매스가 되어 진입, 조망, 채광의 방향성을 강화한다.
- 원본: [스캔 33](./스캔_smallpdf_33.jpg)

### 스캔 34 — 책 76–77쪽: Embed

- **Subtract / Multi Volume.** 작은 볼륨을 큰 볼륨에 밀어 넣어 삽입 자리와 절삭 관계를 만든다.
- Nest가 큰 공간 안에 작은 공간을 포개는 Add 관계라면, Embed는 접촉부를 파고 들어가는 Subtract 관계다.
- 원본: [스캔 34](./스캔_smallpdf_34.jpg)

### 스캔 35 — 책 78–79쪽: Extract

- **Subtract / Multi Volume.** 겹친 제2 볼륨을 밖으로 빼내면서 교차 영역을 제거한다.
- 제거된 자리에는 포켓형 보이드나 깊은 홈이 남는다.
- 원본: [스캔 35](./스캔_smallpdf_35.jpg)

### 스캔 36 — 책 80–81쪽: Inscribe

- **Subtract / Multi Volume.** 가느다란 볼륨으로 표면이나 가장자리에 선형 홈을 새긴다.
- 긴 채광 틈, 입면 절개, 동선 흔적처럼 ‘선으로 읽히는 비움’을 만든다.
- 원본: [스캔 36](./스캔_smallpdf_36.jpg)

### 스캔 37 — 책 82–83쪽: Puncture

- **Subtract / Multi Volume.** 작은 볼륨을 관통시켜 구멍을 만든다.
- Inscribe가 표면의 홈이라면 Puncture는 매스를 뚫고 지나가는 창·통로·천창에 해당한다.
- 원본: [스캔 37](./스캔_smallpdf_37.jpg)

### 스캔 38 — 책 84–85쪽: Combinations 분류 지도

- 두 조작을 연쇄시키는 조합 목차다.
- 같은 동사를 반복하는 조합에서 시작해 Inscribe → Intersect → Split → Embed → Taper → Bend → Branch → Expand → Shift → Notch → Twist로 이어지는 체인을 만든다.
- 원본: [스캔 38](./스캔_smallpdf_38.jpg)

### 스캔 39 — 책 86–87쪽: Inscribe + Inscribe / Intersect + Intersect

- Inscribe를 두 번 적용하면 평행하거나 교차하는 복수의 선형 홈이 생긴다.
- Intersect를 두 번 적용하면 여러 축이 관통하는 복합 결절 매스가 된다.
- 원본: [스캔 39](./스캔_smallpdf_39.jpg)

### 스캔 40 — 책 88–89쪽: Split + Split / Embed + Embed

- Split 반복은 갈라진 부분을 다시 갈라 다중 분기와 내부 틈을 만든다.
- Embed 반복은 여러 삽입 볼륨이 큰 매스에 단계적·중첩된 자리를 만든다.
- 원본: [스캔 40](./스캔_smallpdf_40.jpg)

### 스캔 41 — 책 90–91쪽: Taper + Taper / Bend + Bend

- Taper 반복은 한 번 좁아진 매스를 다시 수렴시켜 방향성이 강한 형상을 만든다.
- Bend 반복은 한 번 꺾인 볼륨을 다시 꺾어 Z자·곡절형 동선과 외곽을 만든다.
- 원본: [스캔 41](./스캔_smallpdf_41.jpg)

### 스캔 42 — 책 92–93쪽: Branch + Branch / Expand + Expand

- Branch 반복은 각 분기에서 다시 가지가 나오는 수목형 조직을 만든다.
- Expand 반복은 서로 다른 구간이나 방향을 연속 확장하여 단계형 매스를 만든다.
- 원본: [스캔 42](./스캔_smallpdf_42.jpg)

### 스캔 43 — 책 94–95쪽: Shift + Shift / Notch + Notch

- Shift 반복은 여러 부분을 연속해서 어긋나게 하여 지그재그 실루엣을 만든다.
- Notch 반복은 가장자리에 리듬 있는 복수의 홈과 음각을 만든다.
- 원본: [스캔 43](./스캔_smallpdf_43.jpg)

### 스캔 44 — 책 96–97쪽: Inscribe + Intersect / Intersect + Split

- Inscribe 후 Intersect는 홈이 새겨진 볼륨에 다른 매스를 관통시켜 절삭과 교차를 결합한다.
- Intersect 후 Split은 교차된 매스를 다시 갈라 더 복잡한 중심 공간을 만든다.
- 원본: [스캔 44](./스캔_smallpdf_44.jpg)

### 스캔 45 — 책 98–99쪽: Split + Embed / Embed + Taper

- Split 후 Embed는 갈라진 부분에 다른 볼륨을 끼워 넣어 틈을 프로그램화한다.
- Embed 후 Taper는 삽입 관계를 만든 뒤 일부를 점차 좁혀 위계와 방향성을 강화한다.
- 원본: [스캔 45](./스캔_smallpdf_45.jpg)

### 스캔 46 — 책 100–101쪽: Taper + Bend / Bend + Branch

- Taper 후 Bend는 좁아지는 선형 매스를 꺾어 흐름을 전환한다.
- Bend 후 Branch는 꺾인 몸체에서 다시 가지를 분기해 방향 전환과 프로그램 분화를 함께 만든다.
- 원본: [스캔 46](./스캔_smallpdf_46.jpg)

### 스캔 47 — 책 102–103쪽: Branch + Expand / Expand + Shift

- Branch 후 Expand는 분기된 팔 중 일부 또는 전체를 늘려 프로그램 크기 차이를 만든다.
- Expand 후 Shift는 연장된 부분을 어긋나게 하여 테라스·세트백·비대칭 외곽을 만든다.
- 원본: [스캔 47](./스캔_smallpdf_47.jpg)

### 스캔 48 — 책 104–105쪽: Shift + Notch / Notch + Twist

- Shift 후 Notch는 어긋난 매스의 모서리를 다시 파내 복수의 외부 공간을 만든다.
- Notch 후 Twist는 홈이 있는 단면을 비틀어 절개가 입체적으로 회전하는 형상을 만든다.
- 원본: [스캔 48](./스캔_smallpdf_48.jpg)

### 스캔 49 — 책 106–107쪽: Aggregations 분류 지도

- 조작된 단위를 대규모 구성으로 반복하는 다섯 집합 방식이 제시된다: Reflect, Pack, Stack, Array, Join.
- 예시는 Expand, Skew, Inflate, Branch, Bend, Rotate, Taper, Pinch, Split과 연결된다.
- 원본: [스캔 49](./스캔_smallpdf_49.jpg)

### 스캔 50 — 책 108–109쪽: Reflect | Expand

- 먼저 단일 볼륨을 Expand한 뒤 거울상으로 복제한다.
- 반복된 확장부가 마주 보며 규칙적인 홈과 능선을 만드는 대칭 집합이다.
- 원본: [스캔 50](./스캔_smallpdf_50.jpg)

### 스캔 51 — 책 110–111쪽: Reflect + Pack | Skew

- 단위를 Skew한 뒤 Reflect하여 대칭쌍을 만들고, 그 쌍을 Pack하여 촘촘히 채운다.
- 사선 단위가 맞물리는 직물·지붕·입면 패턴으로 발전한다.
- 원본: [스캔 51](./스캔_smallpdf_51.jpg)

### 스캔 52 — 책 112–113쪽: Pack | Inflate

- Inflate된 다면체 단위를 빈틈이 적도록 Pack한다.
- 팽창한 셀들이 군집하여 벌집·세포 같은 다공성 집합을 만든다.
- 원본: [스캔 52](./스캔_smallpdf_52.jpg)

### 스캔 53 — 책 114–115쪽: Pack + Stack | Branch

- Branch 단위를 먼저 Pack하고 그 집합을 다시 Stack한다.
- 수평적 분기 조직이 여러 층으로 쌓이며 고밀도 네트워크가 된다.
- 원본: [스캔 53](./스캔_smallpdf_53.jpg)

### 스캔 54 — 책 116–117쪽: Stack | Bend

- Bend된 단위를 층상으로 반복해 굽은 띠 또는 계단형 집합을 만든다.
- 단위의 굽힘이 전체 집합의 경사와 실루엣을 결정한다.

## 5. 헷갈리기 쉬운 용어 비교

| 비교 | 차이 |
|---|---|
| **Expand vs Extrude** | Expand는 비교적 큰 경계나 전체 구간을 늘리고, Extrude는 선택한 면의 일부를 국부적으로 뽑는다. |
| **Expand vs Inflate** | Expand는 한 방향 연장, Inflate는 대응하는 면을 벌려 폭이나 중심부를 부풀리는 조작이다. |
| **Merge vs Overlap** | Merge는 경계를 지워 한 덩어리로 통합하고, Overlap은 겹쳐도 각 단위의 형상을 남긴다. |
| **Nest vs Embed** | Nest는 큰 볼륨 안에 작은 볼륨을 포개는 내포 관계, Embed는 작은 볼륨이 큰 볼륨을 파고들어 절삭·삽입 흔적을 만드는 관계다. |
| **Intersect vs Interlock** | Intersect는 두 축이 관통 교차하고, Interlock은 홈과 돌출부가 퍼즐처럼 맞물린다. |
| **Shift vs Rotate** | Shift는 평행 이동, Rotate는 축 또는 기준점 주위의 회전이다. |
| **Carve vs Notch** | Carve는 크고 깊게 파내며, Notch는 가장자리에 작고 국부적인 홈을 낸다. |
| **Inscribe vs Puncture** | Inscribe는 표면·가장자리에 홈을 새기고, Puncture는 매스를 관통해 구멍을 만든다. |
| **Skew vs Shear** | 이 책에서 Skew는 면을 비스듬히 밀어 형태를 변위하는 조작, Shear는 사선으로 체적을 잘라 내는 조작이다. |

## 6. 설계에 적용하는 간단한 문장법

형태를 설명할 때 다음 문장 구조를 쓰면 책의 논리를 그대로 활용할 수 있다.

> **기본 매스 + 1차 조작 + 2차 조작 + 집합 방식 + 공간 효과**

예시:

- 기본 주거 매스를 **Shift**하고 각 단위를 **Extrude**하여 남향 발코니를 만든다.
- 중앙 매스를 **Carve**한 뒤 작은 프로그램을 **Nest**하여 중정 주변의 위계를 만든다.
- 선형 동선을 **Bend**하고 끝을 **Branch**하여 세 개의 프로그램 영역으로 분리한다.
- **Taper**한 채광 단위를 **Array**하여 빛의 밀도가 점진적으로 변하는 지붕을 만든다.

이 책의 가장 중요한 포인트는 형태 이름을 외우는 것이 아니라, **무엇을 어디에서 어떤 방향으로 변화시켰는지 동사로 명확히 말하는 것**이다.
