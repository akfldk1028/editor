| **Elemental Starting Point** | 기본 출발 요소 | 복잡한 설계 이전의 단순한 기본 볼륨 |

| **Combination** | 조합 | 두 개 이상의 조작을 순서대로 적용함 |

| **Latent Opportunity** | 잠재된 가능성 | 하나의 조작 안에 아직 드러나지 않은 다양한 공간 결과 |

### 원문 핵심 논리의 정리

- 일상 동사는 움직임과 행위를 설명하므로 공간 변화에도 적용할 수 있다.
- 동사를 쓰면 설계를 능동적이고 유동적인 과정으로 이해할 수 있다.
- 볼륨, 동사, 적용 관계는 공간적·프로그램적 요구에 따라 조정된다.
- 분류는 체계적이지만 경직된 공식이나 정답은 아니다.
- 형태 조작은 외형에 머물지 않고 예상하지 못한 공간 결과를 만드는 데 목적이 있다.
- 조합과 집합은 무한할 수 있으며, 책은 이를 보여 주기 위해 Chain이라는 연쇄 방식을 사용한다.

## D. Combination 조합식 20개

조합은 왼쪽 동사를 먼저 적용하고 오른쪽 동사를 이어서 적용한다. `A + B`와 `B + A`는 결과가 다를 수 있으므로 순서도 설계 언어의 일부다.

| 09 | **Shift + Shift** | 어긋난 부분을 다시 이동한다 | 43 | 94 |
| 10 | **Notch + Notch** | 홈을 낸 뒤 다른 홈을 더 낸다 | 43 | 95 |

| 14 | **Embed + Taper** | 삽입 관계를 만든 뒤 점차 좁힌다 | 45 | 99 |
| 15 | **Taper + Bend** | 좁아지는 매스를 꺾는다 | 46 | 100 |
| 16 | **Bend + Branch** | 꺾인 매스에서 가지를 분기한다 | 46 | 101 |

| 20 | **Notch + Twist** | 홈이 있는 볼륨을 비튼다 | 48 | 105 |

### Chain 연결 순서

`Inscribe → Intersect → Split → Embed → Taper → Bend → Branch → Expand → Shift → Notch → Twist`

같은 동사의 반복 조합은 각 단계의 첫 부분에 배치된다. 이 체인은 가능한 모든 조합의 목록이 아니라 조합을 생성하는 한 가지 체계다.

| **Pack** | 밀집 배치 | 단위 사이의 빈틈 최소화 | 세포·벌집·고밀도 군집 |
| **Stack** | 적층 | 단위를 수직 또는 층상으로 쌓음 | 층, 지층, 테라스, 입체 격자 |
| **Array** | 배열 | 일정 간격과 행·열로 반복 | 규칙적 그리드와 반복 입면 |
| **Join** | 이어 붙이기 | 끝점·접점을 연속 연결 | 사슬, 띠, 선형 네트워크 |

### E-2. 책에 제시된 집합식 9개

| No. | 집합식 | 전체 절차 | 스캔 | 책 쪽 |
|---:|---|---|---:|---:|
| 01 | **Reflect \| Expand** | Expand한 단위를 Reflect | 50 | 108–109 |
| 02 | **Reflect + Pack \| Skew** | Skew → Reflect → Pack | 51 | 110–111 |
| 03 | **Pack \| Inflate** | Inflate한 단위를 Pack | 52 | 112–113 |
| 04 | **Pack + Stack \| Branch** | Branch → Pack → Stack | 53 | 114–115 |
| 05 | **Stack \| Bend** | Bend한 단위를 Stack | 54 | 116–117 |
| 06 | **Array + Stack \| Rotate** | Rotate → Array → Stack | 55 | 118–119 |
| 07 | **Array \| Taper** | Taper한 단위를 Array | 56 | 120–121 |
| 08 | **Join + Array \| Pinch** | Pinch → Join → Array | 57 | 122–123 |
| 09 | **Join \| Split** | Split한 단위를 Join | 58 | 124–125 |

### E-3. 집합 체인

`Reflect → Pack → Stack → Array → Join`

한 방식으로 만든 결과가 다음 방식의 입력이 될 수 있다. 단위 조작과 집합 방식은 별개의 층위이므로, 예를 들어 `Taper`는 단위의 모양을 만들고 `Array`는 그 단위들의 전체 배치를 만든다.

## H. 의미가 비슷한 언어의 구별 규칙

| 언어 쌍 | 구별 기준 |
|---|---|
| **Expand / Extrude / Inflate** | 큰 경계의 연장 / 국부 면의 돌출 / 대응 면을 벌린 팽창 |
| **Merge / Overlap / Intersect** | 하나로 통합 / 일부를 포개되 정체성 유지 / 서로 관통 교차 |
| **Nest / Embed / Lodge** | 큰 것 안에 포갬 / 큰 것에 파묻음 / 둘 사이에 끼워 연결 |
| **Split / Fracture / Puncture** | 갈라 변위 / 균열형 체적 제거 / 관통공 형성 |
| **Carve / Notch / Inscribe** | 크고 깊은 파냄 / 가장자리의 국부 홈 / 선형으로 새긴 홈 |
| **Skew / Shear / Taper** | 면을 비스듬히 이동 / 사선 절단 / 길이를 따라 점진적으로 좁힘 |
| **Shift / Rotate / Lift** | 평행 이동 / 각도 회전 / 수직으로 들어 올림 |
| **Reflect / Array** | 거울상 규칙 / 일정 간격·행·열 규칙 |
| **Pack / Stack / Join** | 빈틈 없이 밀집 / 층상으로 쌓기 / 끝점을 이어 선형화 |

## I. 전체 설계 언어 문장 템플릿

`[Base Volume] + [Operation 1] + [Operation 2] + [Aggregation Method] + [Program/Spatial Outcome]`

예:

- `Single Base Volume + Carve + Offset → Offset Program + Perimeter Services`
- `Branched Programs + Embed → Volume Wrapper + Embedded Entry`
- `Tapered Volume + Array → Thickened Roof + Embedded Program`
- `Rotated Volumes + Overlap → Stacked Cores + Street Facade`

이 문장 구조를 쓰면 형태, 조작 순서, 반복 방식, 프로그램 효과를 하나의 체계 안에서 설명할 수 있다.
